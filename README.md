# Data Analytics & Machine Learning Exercises

This repository contains a set of practical exercises for learning and practicing Data Analytics and Machine Learning.

## Repository Structure

```
.
└── regression/
    ├── food.ipynb
    └── wine.ipynb
```

## food.ipynb
Notebook for predicting food calorie content based on nutritional features such as proteins, fats, carbohydrates, and other macronutrients.

Dataset: https://www.kaggle.com/datasets/utsavdey1410/food-nutrition-dataset

## wine.ipynb
Notebook for predicting red wine quality using physicochemical properties such as acidity, residual sugar, pH, alcohol, and sulphates.

Dataset: https://archive.ics.uci.edu/dataset/186/wine+quality
